# Commonly confused words (US English)

The script flags these as candidates; confirm each in context.

| Pair | Rule of thumb | Example |
|---|---|---|
| its / it's | it's = it is / it has | It's late; the boat lost its mast. |
| your / you're | you're = you are | You're wet; your coat. |
| their / there / they're | possessive / place / they are | They're there with their nets. |
| then / than | time / comparison | taller than him, then she left |
| affect / effect | verb / noun (effect as verb = bring about) | The cold affected her; the effect was slow. |
| lose / loose | misplace / not tight | Don't lose the loose rope. |
| lie / lay | recline (lay, lain) / put (laid, laid) | She lay down; she laid the net down. |
| lead / led | past tense is led | He led them out. |
| breath / breathe | noun / verb | Breathe; one breath. |
| peak / peek / pique | top / look / provoke | It piqued her interest. |
| principal / principle | chief, school head / rule | a matter of principle |
| complement / compliment | completes / praise | |
| discreet / discrete | tactful / separate | |
| elicit / illicit | draw out / illegal | |
| farther / further | distance / degree (US keeps the distinction loosely) | farther down the dock |
| fewer / less | countable / mass | fewer boats, less water |

Real-word typos that no speller catches: form/from, trail/trial, quiet/quite, dairy/diary,
causal/casual, united/untied, angel/angle, martial/marital, then/than, of/off, loose/lose,
county/country, pubic/public. Read for them in the final pass.
