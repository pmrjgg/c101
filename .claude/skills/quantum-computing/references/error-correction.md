# Quantum error correction reference

## 1. Stabilizer basics

- Stabilizer group S: abelian subgroup of the n-qubit Pauli group, -I ∉ S, generated by n - k
  independent generators. Code space = joint +1 eigenspace; dimension 2^k.
- Logical operators: Paulis that commute with all of S but are not in S. Distance d = minimum
  weight of a nontrivial logical operator.
- Syndrome: eigenvalues of the generators, measured with ancillas. An error E flips generator g
  iff E anticommutes with g.
- Degeneracy: errors differing by a stabilizer act identically; optimal decoding picks the most
  likely error class, not the most likely error.
- Knill-Laflamme condition: P E_a† E_b P = c_ab P for all correctable E_a, E_b.

## 2. Code catalogue

| Code | [[n, k, d]] | Properties | Use |
|---|---|---|---|
| Repetition | [[n, 1, n]] for one error type | protects only X or only Z | hardware demos, biased noise (cat qubits) |
| Shor | [[9, 1, 3]] | concatenated repetition | teaching |
| Five-qubit | [[5, 1, 3]] | smallest code correcting any single-qubit error | teaching, small demos |
| Steane | [[7, 1, 3]] | CSS, transversal Clifford gates | concatenation, ion/atom demos |
| Rotated surface | [[d², 1, d]] | 2D nearest-neighbour, weight-4 checks, high threshold | default for superconducting roadmaps |
| 2D color code | [[7,1,3]] smallest | transversal Clifford, weight-6 checks, lower threshold | neutral atoms, magic-state work |
| Bivariate bicycle ("gross") | [[144, 12, 12]] | qLDPC, weight-6 checks, needs long-range couplers | IBM roadmap; ~10x fewer qubits than surface code at similar d |
| Hypergraph product / lifted product | families with k ∝ n | qLDPC, non-local connectivity | memories with high rate |
| Bosonic (cat, GKP) | encodes in an oscillator | biased noise (cat), continuous-variable correction (GKP) | concatenate with repetition or surface codes |

## 3. Thresholds by noise model (surface code)

| Noise model | What fails | Threshold (approx.) |
|---|---|---|
| Code capacity | data qubits only, perfect syndrome | ~10.3% (MWPM), ~10.9% optimal (independent X/Z) |
| Phenomenological | data + measurement errors | ~2.9-3% (MWPM) |
| Circuit-level depolarizing | every gate, reset, measurement, idle | ~0.5-1% |

Never quote a code-capacity threshold as if it applied to hardware. Hardware comparisons use
circuit-level noise, ideally SI1000-style models with measurement error higher than gate error.

## 4. Logical error scaling and memory experiments

```
p_L(d) ≈ A (p / p_th)^((d+1)/2),  A ≈ 0.1, p_th ≈ 0.01        per round, per patch
Λ = p_L(d) / p_L(d + 2)                                         error suppression factor
from N rounds with total logical failure probability P:  ε_round = (1 - (1 - 2P)^(1/N)) / 2
```

Threshold estimate: simulate d = 3, 5, 7 (rounds = d) across p; the crossing of p_L(p) curves is
the threshold for that noise model and decoder. Report confidence intervals (binomial,
e.g. Wilson) for every point; collect until ≥ 100-1000 logical errors per point.

## 5. Simulation pipeline: Stim + PyMatching + sinter

```python
import stim, sinter

def task(d, p):
    c = stim.Circuit.generated(
        "surface_code:rotated_memory_x", distance=d, rounds=d,
        after_clifford_depolarization=p, after_reset_flip_probability=p,
        before_measure_flip_probability=p, before_round_data_depolarization=p)
    return sinter.Task(circuit=c, json_metadata={"d": d, "p": p})

tasks = [task(d, p) for d in (3, 5, 7) for p in (0.001, 0.002, 0.004, 0.006, 0.008, 0.01)]
stats = sinter.collect(num_workers=8, tasks=tasks, decoders=["pymatching"],
                       max_shots=2_000_000, max_errors=1000)
for s in sorted(stats, key=lambda s: (s.json_metadata["d"], s.json_metadata["p"])):
    print(s.json_metadata, s.shots, s.errors, s.errors / s.shots)
```

Single-run version (for debugging a custom circuit):

```python
import numpy as np, pymatching
dem = circuit.detector_error_model(decompose_errors=True)
m = pymatching.Matching.from_detector_error_model(dem)
dets, obs = circuit.compile_detector_sampler(seed=7).sample(100_000, separate_observables=True)
p_fail = np.mean(np.any(m.decode_batch(dets) != obs, axis=1))
```

Debug custom circuits: `circuit.diagram("timeslice-svg")` or `"detslice-svg"` to inspect detectors;
a non-deterministic detector or observable raises an error in `detector_error_model`, which is the
fastest way to find a wrong stabilizer measurement order. `circuit.shortest_graphlike_error()`
returns a minimum-weight logical error, i.e. it checks the circuit-level distance.

## 6. Decoders

| Decoder | Complexity / speed | Accuracy | Use |
|---|---|---|---|
| MWPM (PyMatching 2, sparse blossom) | near-linear in practice, ~µs per round at moderate d | strong for graphlike errors | surface code default |
| Correlated matching | 2 passes | better under Y errors / correlated noise | hardware data |
| Union-find | almost-linear, very fast | slightly below MWPM | real-time FPGA/ASIC |
| BP + OSD | O(n³) worst case for OSD | good for qLDPC | bivariate bicycle, hypergraph product |
| Tensor-network / maximum likelihood | expensive | near optimal | benchmarking, small d |
| Neural (e.g. AlphaQubit) | GPU/accelerator | learns leakage, crosstalk | experimental data with complex noise |

Real-time requirement: decoding throughput ≥ syndrome rate (one round per ~1 µs on
superconducting hardware) and bounded latency, otherwise the backlog grows exponentially for
non-Clifford feed-forward.

## 7. Logical operations

- Paulis: tracked in software (Pauli frame), no physical gates.
- Clifford: lattice surgery (merge/split patches to measure ZZ or XX over d rounds), transversal
  gates where the code allows, code deformation.
- Non-Clifford: magic states |T⟩ injected and consumed by lattice surgery with Clifford corrections.
  15-to-1 distillation reduces error from p to ~35 p³ per output; magic state cultivation
  (Gidney-Shutty-Jones 2024) grows a T state inside a small code with far fewer qubits. Factory
  footprint and rate set the runtime when T-count is large.
- CCZ factories produce Toffoli resources directly (8T-to-CCZ style), often cheaper for arithmetic.

## 8. Pitfalls

- Ignoring measurement errors (use rounds ≥ d, or the quoted p_L is optimistic).
- Ignoring leakage and correlated bursts (cosmic-ray events wipe many qubits simultaneously;
  include them in a hardware-facing estimate or state the omission).
- Reporting physical-qubit counts for a memory experiment as if they applied to computation
  (routing space, factories and decoder hardware add 2-10x).
- Comparing decoders at different noise models or with different numbers of rounds.
- Assuming erasure-biased hardware (neutral atoms, dual-rail) has the same threshold as Pauli
  noise: erasure thresholds are substantially higher; model erasures explicitly in Stim
  (heralded errors) rather than as depolarizing noise.
